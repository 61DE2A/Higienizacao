PDF ⇄ Código

Transforma o PDF em um texto (Base64) que você pode copiar/colar, e reconstrói o PDF original, idêntico, a partir desse texto. Tudo roda no seu navegador — nada é enviado pra nenhum servidor.

PDF → Código
Código → PDF
Clique ou arraste um PDF aqui O arquivo inteiro vira um texto Base64 abaixo, pronto pra copiar
Copie esse texto e guarde onde quiser (e-mail, Google Docs, WhatsApp pra você mesmo). Depois, na aba "Código → PDF", cole de volta pra recuperar o PDF original — exatamente igual, byte a byte.
"Abrir em nova aba" só mostra o PDF no navegador, sem forçar download — útil se o PC bloquear downloads. Ali dá pra ler, imprimir ou salvar via Ctrl+P.
O código gerado é o arquivo original codificado em Base64 — não é uma versão resumida ou reescrita.
